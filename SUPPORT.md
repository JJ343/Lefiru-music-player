# Support

## General questions and help

Use **GitHub Discussions** for questions about how to use the app, configuration, or
general inquiries. Do not use issues for support.

## Reporting bugs

If you think you found a bug, open an issue using the "Bug report" template in
`.github/ISSUE_TEMPLATE`. Please include:

* App version and build code.
* Android version and device model.
* Steps to reproduce the bug and what you expected to happen.
* Screenshots or logs, if available.

## Feature requests

Use the "Feature request" template in `.github/ISSUE_TEMPLATE` to suggest new
functionality.

## Security

To report security vulnerabilities, see `SECURITY.md` (private report, not public
issues).
