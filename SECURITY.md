# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.1 (code 2) | ✅ |
| 1.0 | ❌ |

## Reporting a vulnerability

Do not use public issues to report security vulnerabilities. Write to me privately at
opensource+security@lefiru.example.

Please include:
* App version and build code.
* Android version and device model.
* Steps to reproduce the issue.
* Possible impact and, if applicable, a proposed mitigation.

I will respond within **5 business days** and keep you informed of progress until it is resolved.

## Project scope

Lefiru is a local music player with no internet access. It never uploads your audio files to any
server nor shares them with third parties. Favorites, playlists, and settings are stored locally
on the device (DataStore).
